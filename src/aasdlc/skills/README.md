# Skills

Core skills, one folder each. A skill folder contains `SKILL.md` (frontmatter `name` and
`description`, then instructions) and optionally `references/` and `templates/`.

Three kinds live here: phase skills (one per methodology step), discipline skills (how the agent
behaves inside any step), and the `aasdlc` meta skill that routes to them. See sections 3 and 4 of
`docs/design.md`.
