Project-scope install of the framework's own commands for the Claude Code target. Each file in
commands/ is a thin wrapper that reads a skill under src/aa-sdlc/skills/fw/. Open Claude Code in
this folder to use /aa-internal-new-opinion, /aa-internal-new-tenet, /aa-internal-new-discipline,
/aa-internal-new-process, and /aa-internal-new-step. See src/aa-sdlc/targets/claude-code/README.md.
